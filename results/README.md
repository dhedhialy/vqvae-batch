# Atlas V6 Disentanglement — Results Summary

Run: `atlas_v6_log1p_s20260809` checkpoint `best.pt` (epoch 12, recon_loss 0.264).
Full scorecard: `results/scorecard_report.md` (+ one PNG per bundle) generated by `make_scorecard_report.py`.

## What is being compared

Seven views of the **same sampled cells** are scored under identical labels:

| View | Meaning |
|---|---|
| `input_expression` | raw normalized-log1p expression (reference / upper bound) |
| `encoder_z_e` | continuous encoder output before code selection |
| `bio_z_q` | quantized biological latent (32 axes x 64-d codes) |
| `bio_code_onehot` | discrete 512-d code indicator |
| `technical_embedding` | dataset/assay technical branch alone |
| `bio_reconstruction` | reconstruction from bio codes only |
| `full_reconstruction` | bio + technical branch reconstruction |

Targets: dataset-id / assay leakage (want low on bio, high on tech), coarse + fine
cell type and cross-dataset transfer (want high on bio), iLISI/cLISI/kBET,
per-axis NMI, conditional code-usage TV (the eval twin of the training loss).

## Headline verdicts (thresholds: bio leakage <= 0.5x input, bio retention >= 0.9x input)

| Bundle | bio_z_q dataset leak (rel. to input) | leakage reduced? | bio retention (rel.) | **disentangled?** | tech branch |
|---|---|---|---|---|---|
| In-distribution (atlas test) | 0.966 | No | 1.051 | **No** | encodes dataset, **not** free of biology |
| OOD unseen protocol | 0.842 | No | 0.992 | **No** | ~no dataset readout (by design), free of biology |
| OOD unseen tissue | 0.915 | No | 1.066 | **No** | ~no dataset readout, not free of biology |
| OOD disease | 0.585 | No (barely under bar anyway) | 1.138 | **No** | ~no dataset readout, free of biology |

Key observation: **bio codes still carry nearly as much dataset information as the
raw input** in-distribution (leakage ratio 0.97, dataset probe acc 0.522 vs 0.538
for input). The `conditional_code_usage_weight: 0.02` alignment is not strong
enough for full batch removal. Biology (coarse cell type probe ~0.83, cross-dataset
transfer ~0.75) is well preserved — so the model is a good autoencoder, just not
yet a good disentangler on the bio-latent axis.

### Technical branch (scVI-style behavior check)

- In-distribution: `technical_embedding` predicts dataset at 0.978 and assay at 1.0 —
  the branch encodes the known technical offsets as designed.
- On unseen datasets: dataset readout drops to ~0.74–0.77 (unknown -> zero offset), while
  `full_reconstruction` can still read datasets via bio code leakage — confirming the
  leak is in the bio side, not the technical side.

### Axis structure

- Codebooks healthy: 16/16 codes active per axis, 0 dead codes, entropy ~0.99.
- Top batch-leaking axes: 5, 30, 6, 13, 11 (ID); top biological axes: 21, 10, 18, 9, 29.
- Per-axis conditional code-use TV ranges ~0.05–0.14 (target is much lower for clean separation).

## Matched-biology experiment (running)

Manifest `atlas_matched_biology_v2`: cerebral cortex, healthy >= 80%, age 10–90,
>= 10k cells & 3 coarse types per dataset. 34 of 210 datasets eligible.

| Split | Datasets | Cells (train/val/test) | Assay |
|---|---|---|---|
| `atlas_matched_biology_v2_train` | 26 | 697,323 / 154,527 / 168,975 | 10x 3' v3 |
| `atlas_matched_biology_v2_matched_ood` | 8 | 228,740 / 20,839 / 34,671 | 10x 3' v3 |

Whole datasets are held out (balanced by dataset, not cells), so the matched-OOD
rung = pure batch transfer test: unseen datasets with matched biology.

**Controlled retrain** launched on GPU 0: `atlas_matched_bio_v2_s20260815`
(12 epochs, batch 2048, same v6 config -> note: nuisance categories are only
27 datasets / 1 assay / 6 coarse cell types, vs 210/… for the atlas model).

## Interpretation ladder (from the study plan)

- Bio codes mix unseen **matched** datasets while cell-type transfer holds → technical factors were peeled off (transferable batch info).
- Bio codes mix protocol-OOD but lose cell type → over-correction.
- Technical branch predicts seen assays but is ~zero on unseen (by design) while bio stays informative → scVI-style separation works.
- Bio codes look batch-free in-distribution but leak on matched OOD → the model fitted dataset-specific quirks, not transferable batch factors (failure mode to rule out).
